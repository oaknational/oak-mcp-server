# Security policy

## Reporting a vulnerability

Do not report a security issue in a public issue or pull request.

Use this repository's private vulnerability reporting. Open the [Security tab](https://github.com/oaknational/oak-mcp-server/security) and choose "Report a vulnerability", or go straight to the [private report form](https://github.com/oaknational/oak-mcp-server/security/advisories/new). Only the maintainers can see your report.

Oak National Academy also publishes its organisation-wide policy at <https://www.thenational.academy/.well-known/security.txt>.

## Credentials

- Real credentials stay in untracked local files such as `.env` and `.env.local`.
- Tracked files hold placeholders only.
- Any exception to secret scanning must be explicit and justified.
